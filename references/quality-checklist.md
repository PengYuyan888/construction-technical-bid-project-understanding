# 质量检查清单

## 事实

- [ ] 项目名称、地点、建设单位、标段与当前项目身份卡一致。
- [ ] 每个数字、单位、范围、材料和做法可在事实台账中追溯。
- [ ] 最新补充通知和澄清答疑已覆盖原版本。
- [ ] 未把参考标书、通用规范或经验数据写成本项目事实。
- [ ] 冲突和缺失未被擅自补齐。

## 内容

- [ ] 新建项目以新建分支为主，改造项目才写既有病害和使用影响。
- [ ] 项目定位、建设意义和特点有事实支撑，篇幅与用户要求相符。
- [ ] 工程概况覆盖招标范围内主要单体、专业和专项工程。
- [ ] 现状分析覆盖场地、周边、交通、地质水文、管线和临时条件中已有资料的部分。
- [ ] 概况表中没有混入施工部署、管理措施或我方承诺。

## 语言

- [ ] 没有“依据资料整理、编制思路、我们认为”等过程性文字。
- [ ] 没有互联网行业腔和空泛套话。
- [ ] 表格句子主谓宾完整，参数说明了部位和用途。
- [ ] 没有“按图、详大样、按相关要求”等含糊引用。
- [ ] 特点具体，不只写“规模大、专业多、工期紧、协调难”。

## Word 和版式

- [ ] 已使用用户模板；无模板时已取得使用内置模板的明确授权。
- [ ] 一级至三级标题未越权修改，四级标题调整与计划一致。
- [ ] 表格样式、列宽、边框、题注和图片标题与模板一致。
- [ ] 表格分点是独立 Word 段落，没有手动换行或可见的 `^p`。
- [ ] 未擅自加入分页符、分节符、填充色或新样式。
- [ ] 全部页面已渲染检查，无溢出、遮挡、空白页、表格截断和图片失真。
- [ ] 无批注、修订痕迹、外链图片和临时路径依赖。

## 修改稿

- [ ] 已先提交修改计划并取得确认。
- [ ] 原文件未覆盖，输出文件名可区分版本。
- [ ] “其他内容不动”时已做包部件差异检查。
- [ ] 只交付用户要求的成品；内部台账和 QA 文件未混入交付目录。
