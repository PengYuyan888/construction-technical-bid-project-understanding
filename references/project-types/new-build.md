# 新建项目分支（默认）

新建工程是本 Skill 的主要应用对象。不要把改造项目中的“病害、居民影响、边施工边使用”等表述机械套入新建项目。

## 项目定位

从招标功能、建设规模、服务对象、规划关系和建筑类型出发，说明项目承担的实际功能及在片区或建设体系中的作用。可以提升表达，但不得自行赋予“地标、示范、首个、最高等级”等称号。

## 建设意义

可从以下已被资料支持的方向展开：

- 完善公共服务或生产生活配套；
- 提升土地和空间使用效能；
- 改善城市功能、产业载体或民生服务条件；
- 落实绿色、韧性、安全和高品质建设要求；
- 带动片区功能衔接和长期运营。

意义应紧扣项目用途，不套用与项目无关的宏大政策表述。

## 基本概况

优先用表格列明：项目名称、地点、建设单位、招标范围、建筑用途、用地和建筑规模、楼栋及层数、高度、地下室、结构形式、基础形式、工期、质量安全目标和专业工程构成。缺失项删除或标为待确认，不填经验值。

## 不同建筑类型的补充重点

|类型|重点读取和归纳|
|---|---|
|住宅及配套|住宅楼栋、户型与配套、公区、地下车库、人防、消防、园林和市政接驳|
|公共建筑|服务对象、功能分区、人员密集场所、防火疏散、无障碍、机电系统和室外配套|
|商业综合体|商业业态、塔楼裙房、地下空间、装卸后勤、幕墙、机电负荷和消防系统|
|学校|学段和规模、教学与生活分区、运动场地、食堂宿舍、消防疏散和校园流线|
|医院|医疗功能、洁污分流、感染控制、医用专项、物流流线、净化和备用保障系统|
|场馆|大跨空间、看台与人流组织、声光电、屋盖、设备吊挂和大型设备进场条件|
|工业厂房|生产工艺、柱网与荷载、层高、吊车、动力介质、洁净或防爆要求、物流和室外管廊|
|超高层或高层综合建筑|深基坑、竖向运输、结构体系、幕墙、超高层机电、消防和施工场地条件|

## 施工现场现状

新建项目应重点写：红线和场地移交状态、地形高差、地质水文、周边道路和出入口、邻近建构筑物、地下和架空管线、临水临电、可用场地、交通限制及分期交付。未提供现场踏勘或勘察资料时，不得写“场地平整、交通便利、无地下管线”等推断。

## 项目特点

从真实规模、结构、专业系统、场地、工期、功能和质量目标中提炼。特点表达应具体，例如“大跨度钢结构屋盖与机电吊挂交叉集中”，而不是“专业协调难度大”。施工对策放在后续施工组织章节，本章只作必要、简洁的认识说明。
